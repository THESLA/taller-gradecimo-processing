1 for() — Repite sin escribir de más

Ejercicio 1: "Diez círculos"

for repetir i

¿Qué vamos a aprender? Si quieres dibujar 10 círculos seguidos, ¡no tienes que escribir 10 veces la línea de ellipse()! Con el bucle for escribes el código UNA vez y él lo repite las veces que quieras. La variable i va contando: 0, 1, 2, 3... y puedes usarla para cambiar la posición.

Paso 1: Copia esto en tu cuaderno

// for: repite 10 veces dibujando círculos

void setup() {
  size(400, 200);
}

void draw() {
  background(30, 30, 60);
  
  for (int i = 0; i < 10; i++) {
    fill(52, 152, 219);
    // i va cambiando: 0,1,2... cada uno un lugar distinto
    ellipse(i * 40 + 20, 100, 30, 30);
  }
}

Paso 2: Escríbelo en Processing y ejecútalo

Mira cómo aparecen 10 círculos azules en fila. Cambia el 10 por 20 y observa qué pasa. Luego cambia el 40 por 10. ¿Cuántos círculos alcanzan a caber?

Paso 3: Muéstraselo al profesor

Muestra al profesor tu fila de círculos y tu cuaderno con el código copiado. Explícale qué hace la variable i.

Modifica y experimenta

1. Cambia el color del fill() para que cada círculo sea de un color diferente, usando i: fill(i * 25, 100, 200).
2. Haz una fila vertical cambiando i * 40 + 20 y la posición y.
3. Cambia el tamaño del círculo: ellipse(i * 40 + 20, 100, i, i) — los círculos crecen con cada repetición.

Para pensar

¿Por qué el primer círculo queda en x = 20 y no en x = 0? (Pista: cuando i = 0, ¿cuánto vale i * 40 + 20? ¿Y cuando i = 9?)

2 for + random() — Cielo estrellado

Ejercicio 2: "Cielo estrellado"

for random width/height

¿Qué vamos a aprender? Combinando for con random() podemos generar 100 estrellas en 5 líneas de código. Cada estrella nace en una posición aleatoria. También aprenderás las variables especiales width y height (el tamaño del canvas).

Paso 1: Copia esto en tu cuaderno

// Cielo estrellado: 100 estrellas con random

void setup() {
  size(400, 400);
  background(20, 20, 50);
  
  for (int i = 0; i < 100; i++) {
    float x = random(width);
    float y = random(height);
    float t = random(1, 4);  // tamaño 1 a 4
    
    fill(random(200, 255), random(200, 255), 200);
    ellipse(x, y, t, t);
  }
}

void draw() {
  // Está vacío: las estrellas ya quedaron dibujadas
}

Paso 2: Escríbelo en Processing y ejecútalo

Cada vez que ejecutas, las estrellas salen en lugares DIFERENTES gracias a random(). Presiona Play varias veces para verlo. Cambia el 100 por 1000… ¡todo un cielo!

Paso 3: Muéstraselo al profesor

Muestra tu cielo estrellado y tu cuaderno con el código copiado. Explica qué hace random(width) y por qué el cielo cambia cada vez.

Modifica y experimenta

1. Agrega una luna amarilla fija en una esquina (fill(243, 156, 18); ellipse(50, 50, 40, 40);).
2. Haz que algunas estrellas parpadeen: guarda las estrellas en variables globales y dibújalas en draw() con un alpha aleatorio.
3. Cambia el cielo por un fondo de confeti de colores completamente aleatorios.

Para pensar

¿Por qué dibujamos en setup() y no en draw()? ¿Qué pasaría si el código del for estuviera dentro de draw()?

3 mouseDragged() — Pintar arrastrando

Ejercicio 3: "Pincel mágico"

mouseDragged eventos

¿Qué vamos a aprender? mousePressed() se ejecuta UNA vez al hacer clic. mouseDragged() se ejecuta continuamente mientras mantienes el click y arrastras… ¡perfecto para pintar! Es como un pincel que dibuja mientras lo mueves.

Paso 1: Copia esto en tu cuaderno

// Pincel mágico: pintas mientras arrastras

void setup() {
  size(400, 400);
  background(30, 30, 60);
}

void draw() {
  // Vacío: background NO se repite para no borrar
}

void mouseDragged() {
  // Aleatorios: color y tamaño de cada pincelada
  fill(random(255), random(255), random(255), 150);
  ellipse(mouseX, mouseY, random(10, 40), random(10, 40));
}

Paso 2: Escríbelo en Processing y ejecútalo

Mantén presionado el mouse y muévelo por el canvas. ¡Estás pintando con colores sorpresa! Importante: el background() está solo en setup() para que no borre tu dibujo en cada frame.

Paso 3: Muéstraselo al profesor

Pinta una pequeña obra de arte y muéstrasela al profesor con tu cuaderno donde tengas el código copiado.

Modifica y experimenta

1. Cambia la transparencia: usa random(50, 200) como 4to valor del fill() para pinceladas más suaves.
2. Agrega stroke() con un color para darle un borde a cada pincelada.
3. Combina con keyPressed(): al presionar 'b' el fondo se reinicia con background(30, 30, 60); para empezar de nuevo.

Para pensar

¿Qué diferencia hay entre mousePressed(), mouseDragged() y mouseIsPressed? ¿Para qué crees que serviría cada uno?

4 Funciones propias — Tú creas tus órdenes

Ejercicio 4: "Mi función de flor"

void funciones parámetros

¿Qué vamos a aprender? Hasta ahora solo usábamos funciones que ya existían (ellipse(), fill()...). ¡Ahora vas a crear TUS PROPIAS funciones! Una función es una mini-máquina con nombre que puedes usar muchas veces. A los datos que recibe se les llama parámetros (cx, cy, tamaño).

Paso 1: Copia esto en tu cuaderno

// Función propia: dibujaFlores con parámetros

void setup() {
  size(400, 400);
}

void draw() {
  background(30, 30, 60);
  
  // Llamamos a NUESTRA función 3 veces
  dibujaFlor(100, 300, 50);
  dibujaFlor(300, 100, 70);
  dibujaFlor(mouseX, mouseY, 30);
}

// Nuestra función: dibuja una flor en (cx, cy) con tamaño t
void dibujaFlor(float cx, float cy, float t) {
  // 4 pétalos (rojos)
  fill(231, 76, 60);
  ellipse(cx - t/2, cy, t/3, t/3);
  ellipse(cx + t/2, cy, t/3, t/3);
  ellipse(cx, cy - t/2, t/3, t/3);
  ellipse(cx, cy + t/2, t/3, t/3);
  
  // Centro (amarillo)
  fill(243, 156, 18);
  ellipse(cx, cy, t/3, t/3);
}

Paso 2: Escríbelo en Processing y ejecútalo

Verás 3 flores: dos fijas y una que sigue tu mouse. Prueba agregar más flores cambiando los números. ¿Qué pasa si llamas a dibujaFlor() 10 veces con un for?

Paso 3: Muéstraselo al profesor

Muestra tus flores y tu cuaderno con el código. Explica qué son los parámetros cx, cy y t.

Modifica y experimenta

1. Crea una función dibujaCasa(float cx, float cy, float t) con un rectángulo y un triángulo de techo.
2. Haz un jardín: usa un for para sembrar 10 flores en fila.
3. Haz tu función dibujaEstrella(): 4 pétalos con la función que ya tienes… ¡las funciones pueden llamar a otras funciones!

Para pensar

¿Por qué es útil crear funciones? ¿Qué pasaría si quisiéramos dibujar 50 flores sin funciones?

5 Tu primer juego — Atrapa la estrella

Ejercicio 5: "Atrapa la estrella"

juego dist score todo combinado

¿Qué vamos a aprender? ¡Llegó el momento de juntar TODO lo que sabes para hacer tu primer videojuego! Aprenderás dist() (distancia entre dos puntos), cómo sumar puntos (score = score + 1) y cómo crear una función nuevaEstrella() que ponga la estrella en otro lugar.

Paso 1: Copia esto en tu cuaderno

// JUEGO: atrapa la estrella con clics
float estrellaX, estrellaY;
int puntos = 0;

void setup() {
  size(400, 400);
  nuevaEstrella();  // estrella en un lugar al azar
}

void draw() {
  background(30, 30, 60);
  
  // La estrella que debes atrapar
  fill(243, 156, 18);
  ellipse(estrellaX, estrellaY, 30, 30);
  
  // Tu "mano" que sigue al mouse
  fill(52, 152, 219, 100);
  ellipse(mouseX, mouseY, 40, 40);
  
  // Marcador de puntos
  fill(255);
  textSize(20);
  text("Puntos: " + puntos, 10, 30);
}

void mousePressed() {
  // dist = distancia entre el clic y la estrella
  if (dist(mouseX, mouseY, estrellaX, estrellaY) < 40) {
    puntos = puntos + 1;  // ¡Atrapada!
    nuevaEstrella();        // La estrella se mueve
  }
}

// Nuestra función: pone la estrella en un lugar aleatorio
void nuevaEstrella() {
  estrellaX = random(30, width - 30);
  estrellaY = random(30, height - 30);
}

Paso 2: Escríbelo en Processing y ejecútalo

Haz clic sobre la estrella amarilla para atraparla. Cada vez que la atrapas, sumas un punto y la estrella salta a otro lugar. ¡Consigue el máximo de puntos en 10 clics!

Paso 3: Muéstraselo al profesor

Demuestra tu juego funcionando, suma al menos 3 puntos frente al profesor y muestra tu cuaderno con el código copiado.

Modifica y experimenta

1. Hazlo más difícil: cambia la estrella a 20 de tamaño (tienes que estar más cerca) o haz que se mueva con animación.
2. Agrega vidas: si fallas 3 veces, el juego termina (noLoop(); detiene el programa).
3. Agrega un tiempo límite: la estrella se mueve sola cada 2 segundos usando frameCount.
4. Cambia la estrella por otro animal o figura usando una función propia.

Para pensar

¿Por qué usamos dist() < 40 y no comparamos la posición exacta? ¿Qué pasaría si el clic tuviera que caer exactamente sobre un punto?

6 Tu proyecto personal — Taller 2

Crea tu propio juego o composición

Usa todo lo aprendido en los dos talleres. Puedes mejorar el juego "Atrapa la estrella" o inventar uno totalmente nuevo. Tu proyecto debe incluir:

for()

Algo repetido: filas, estrellas, enemigos...

random()

Colores, posiciones o tamaños aleatorios

Una función propia

void miFuncion(float cx, float cy) usada al menos 2 veces

mousePressed() o mouseDragged()

Interacción con clic

keyPressed()

Acción con una tecla (reiniciar, cambiar velocidad...)

Puntos o meta

Un marcador (score), un nivel o un objetivo claro

Ideas para inspirarte:

• Atrapa la estrella con vidas, niveles y sonido visual (la estrella cambia de color)
• Esquiva los meteoritos: figuras que caen con random y tu personaje se mueve con teclas
• Jardín interactivo: cultiva flores con clics y riégalas con el mouse
• Mariposas: 20 mariposas que vuelan con random y tú las atrapas
• Paula (reloj) de colores: figuras que orbitan con for y cambian con teclas
