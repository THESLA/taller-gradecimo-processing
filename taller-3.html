Taller 3: Tarjeta de Presentación

Tu escarapela para la Feria de Ciencias — hecha 100% con figuras en Processing

EVALUACIÓN • Taller Gradécimo Processing

Lo que necesitas para este taller

  • De los talleres 1 y 2: setup(), draw(), figuras, colores, text(), random(), keyPressed()
  • Usar variables de color que puedas cambiar
  • Escribir tu propia información (nombre, colegio, proyecto)
  • La regla de oro: oprimir cualquier tecla cambia TODOS los colores al azar

Tu tarea (evaluación periódica)

Debes crear en Processing una escarapela de identificación (como la que se lleva en la Feria de Ciencias) usando solo figuras (rect, ellipse, line, triangle, etc.) y texto. La tarjeta debe mostrar TODOS tus datos: nombre completo, grado, edad, peso, estatura, tipo de sangre / RH, proyecto, categoría, municipio y fecha.

El reto especial: cada vez que oprimas cualquier tecla, los colores del fondo, de las letras y de las demás figuras deben cambiar de forma aleatoria. Observa la escarapela de referencia de abajo y constrúyela desde cero en tu computador, con tus propios datos.

2 La técnica clave: colores que cambian con teclas

El truco que debes aprender

Para que los colores cambien, NO escribes los colores directo en la figura. Guardas cada color en una variable, y en keyPressed() le asignas un valor aleatorio con random(). Así, al oprimir tecla, ¡todo se repinta solo!

Copia este truco en tu cuaderno

// 1. Variables para guardar los colores
float rFondo, gFondo, bFondo;   // color del fondo
float rTexto, gTexto, bTexto;  // color de las letras
float rFig, gFig, bFig;        // color de las figuras

void setup() {
  size(500, 350);
  // Colores iniciales (los elijes tú)
  rFondo = 30;  gFondo = 30;  bFondo = 80;
  rTexto = 255; gTexto = 200; bTexto = 0;
  rFig = 46;   gFig = 204;   bFig = 113;
}

void draw() {
  background(rFondo, gFondo, bFondo);  // usa la variable
  // ... dibuja marco, figuras y texto con las variables ...
}

// 2. ¡Al oprimir tecla, cambian TODOS los colores!
void keyPressed() {
  rFondo = random(255);  gFondo = random(255);  bFondo = random(255);
  rTexto = random(255);  gTexto = random(255);  bTexto = random(255);
  rFig   = random(255);  gFig   = random(255);  bFig   = random(255);
}

Paso: pruébalo en Processing

Escribe este truco, dibuja tu tarjeta usando las variables de color, y oprime cualquier tecla mientras el programa corre. Verás que todo cambia de color. ¡Esa es la magia!

Código completo de la tarjeta de referencia (SOLO PARA EL PROFESOR — los alumnos no deben copiarlo) 
// ESCARAPELA REFERENCIA - NO COPIAR (es evaluación)
float rF, gF, bF;   // fondo
float rT, gT, bT;   // título
float rE, gE, bE;   // emblema y figuras
float rM, gM, bM;   // marco
float rD, gD, bD;   // texto de datos
float rP, gP, bP;   // panel interior

void setup() {
  size(520, 470);
  rF = 25;  gF = 40;  bF = 90;
  rT = 255; gT = 210; bT = 40;
  rE = 46;  gE = 204; bE = 113;
  rM = 243; gM = 156; bM = 18;
  rD = 230; gD = 230; bD = 255;
  rP = 15;  gP = 25;  bP = 55;
}

void draw() {
  background(rF, gF, bF);

  // Marco exterior
  stroke(rM, gM, bM); strokeWeight(6); noFill();
  rect(15, 15, width-30, height-30, 20);

  // Panel interior
  noStroke(); fill(rP, gP, bP);
  rect(30, 30, width-60, height-60, 14);

  // Título
  fill(rT, gT, bT); textAlign(CENTER, CENTER);
  textSize(30); text("FERIA DE CIENCIAS", width/2, 65);
  textSize(13); fill(rD);
  text("INSTITUCIÓN EDUCATIVA — MUNICIPIO", width/2, 92);

  // Emblema (átomo)
  stroke(rE, gE, bE); strokeWeight(3); noFill();
  ellipse(width/2, 140, 55, 30);
  ellipse(width/2, 140, 30, 55);
  noStroke(); fill(rE, gE, bE);
  ellipse(width/2, 140, 24, 24);

  // Círculo "foto"
  stroke(rM, gM, bM); strokeWeight(3); noFill();
  ellipse(width/2, 200, 46, 46);
  noStroke(); fill(rE, gE, bE, 120);
  ellipse(width/2, 200, 40, 40);

  // DATOS del estudiante (alineados a la izquierda)
  fill(rD); textAlign(LEFT, CENTER); textSize(14);
  int x = 55; int y = 250;
  text("Nombre: __________________________", x, y); y = y + 28;
  text("Grado: 10°          Edad: ______ años", x, y); y = y + 28;
  text("Peso: ______ kg     Estatura: ______ cm", x, y); y = y + 28;
  text("Tipo de sangre (RH): O+", x, y); y = y + 28;
  text("Proyecto: ________________________", x, y); y = y + 28;
  text("Categoría: _______________________", x, y); y = y + 28;
  text("Municipio: ________   Fecha: ______", x, y);

  // Esquinas decorativas
  fill(rE, gE, bE);
  ellipse(40, 40, 10, 10); ellipse(width-40, 40, 10, 10);
  ellipse(40, height-40, 10, 10); ellipse(width-40, height-40, 10, 10);
}

void keyPressed() {
  rF = random(255); gF = random(255); bF = random(255);
  rT = random(255); gT = random(255); bT = random(255);
  rE = random(255); gE = random(255); bE = random(255);
  rM = random(255); gM = random(255); bM = random(255);
  rD = random(255); gD = random(255); bD = random(255);
  rP = random(255); gP = random(255); bP = random(255);
}
3 Qué debe tener TU tarjeta (requisitos)

Lista de requisitos obligatorios

  • Figuras: mínimo usa rect (marco) y ellipse (emblema/logo y foto), más las que quieras (líneas, triángulos, estrellas...)
  • Nombre y grado: tu nombre completo y tu grado (ej. 10°)
  • Edad: tu edad en años (ej. "Edad: 15 años")
  • Peso y estatura: tu peso en kg y tu estatura en cm
  • Tipo de sangre / RH: obligatorio (ej. O+, A-, B+, AB-)
  • Proyecto y categoría: el nombre de tu proyecto y su categoría en la feria
  • Municipio y fecha: tu municipio y la fecha del evento
  • Colores variables: fondo, letras, figuras y panel deben usar variables de color (no números fijos por figura)
  • keyPressed(): al oprimir cualquier tecla, TODOS los colores (fondo + letras + figuras + panel) cambian con random()
  • Originalidad: tu tarjeta debe ser diferente a la de referencia (otro logo, otros textos, tu propio estilo)
  • Orden: código organizado, con comentarios, en tu cuaderno y en Processing
Ideas para tu emblema (logo con figuras)

• Un átomo (círculo + 2 órbitas)  • Un planeta con anillo  • Un escudo (rect + triángulo)  • Una estrella de 5 puntas  • Un engranaje  • Un cerebro o un libro simplificado  • Flores (como en el Taller 2)

4 Cómo entregar tu trabajo

Paso 1: Planifica en tu cuaderno

Dibuja en papel cómo va a quedar tu tarjeta: dónde va el título, el emblema, los textos. Anota las variables de color que vas a usar. Copia el "truco" de la sección 2 a mano.

Paso 2: Construye en Processing

Abre Processing, escribe tu código. Dibuja el marco, el emblema, los textos y la decoración usando tus variables de color. Prueba que se vea bien.

Paso 3: Prueba las teclas

Oprime varias teclas. Si todos los colores cambian al azar, ¡funciona! Si falta alguno, revisa que usaste la variable en TODAS las figuras y textos.

Paso 4: Muéstraselo al profesor

Guarda tu archivo como TuNombre_Tarjeta.pde. Muestra la tarjeta funcionando (oprime teclas frente al profesor) y tu cuaderno con el plan y el código. Explica cómo funciona el keyPressed() con random().
